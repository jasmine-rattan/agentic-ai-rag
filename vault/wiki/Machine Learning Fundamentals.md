# Machine Learning Fundamentals

## Summary
This meeting covered fundamental concepts in machine learning, focusing on extrapolation, model evaluation, and reinforcement learning. Key topics included understanding the risks of extrapolation when dealing with unseen data, techniques for handling internal company data without cloud integration, and the importance of model validation and understanding bias and variance. The discussion also touched on algorithm selection, training complexity, and the role of learning rate.

## Key Concepts
*   **Extrapolation:** Predicting values beyond the range of the training data. This is risky and prone to error, particularly when dealing with significantly different data distributions.
*   **Model Evaluation:** Assessing a model's performance using training, validation, and test datasets. This involves measuring loss and understanding metrics like bias and variance.
*   **Bias and Variance:** Bias refers to systematic errors in a model's predictions, while variance refers to the model's sensitivity to changes in the training data.
*   **Model Validation:** The process of ensuring a model generalizes well to unseen data through techniques like splitting data into training, validation, and test sets.
*   **Algorithm Selection:**  Choosing an appropriate algorithm based on the problem, data size, and computational resources, considering factors like training complexity and learning rate.
