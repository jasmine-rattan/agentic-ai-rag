# Markdown System Prompts Tokens

**Summary:** This meeting explored the use of Markdown for knowledge base creation, the concept of system prompts in Large Language Model (LLM) interactions, and the nuances of tokenization across different LLM models. Key takeaways include the importance of well-defined system prompts for consistent LLM behavior, the general applicability of tokenization concepts beyond LLMs, and the ability to fine-tune LLM “memories” through modified Markdown files.

**Key Concepts:**

*   **Markdown:** A lightweight markup language used for formatting text, particularly for creating structured documents and knowledge bases.
*   **System Prompts:** Instructions given to an LLM that dictate its behavior and response style, typically embedded within a configuration file like Claude MD or Agent MD. These shape the LLM's persona and guide its responses.
*   **Tokenization:** The process of breaking down text into smaller units (tokens) for LLM processing.  Different models use different tokenizers, though the goal is for tokens to be generally comparable across models.
*   **LLM “Memories”:** The learned knowledge and associations stored within an LLM, often represented and manipulated through Markdown files.
