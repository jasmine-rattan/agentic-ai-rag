# AI Agents Answer Action

**Summary:**

This class explores the concept of AI agents, moving beyond simple LLM responses to systems capable of autonomous action. It introduces key concepts like the "agent loop" – a continuous process of observation, thinking, action, and feedback – and highlights the role of tools and harnesses in enabling agents to achieve complex goals. The class focuses on how LLMs can initiate and drive automated agent behavior, including tool calls and iterative refinement.

**Key Concepts:**

*   **AI Agent:** An AI system with agency, possessing the ability to choose and execute actions towards a defined goal.
*   **Agent Loop:** A continuous process involving observation, reasoning, action selection, and feedback, forming the core of an agent's operation.
*   **Tool Calls:** The ability of an LLM to invoke external tools (e.g., web search) to augment its knowledge and capabilities.
*   **RAG (Retrieval-Augmented Generation):** Utilizing retrieved context from sources to ground LLM responses and improve accuracy.
*   **ReAct:** A debugging loop combining reasoning and acting to correct errors and improve agent performance.
