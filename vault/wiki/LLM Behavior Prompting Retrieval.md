# LLM Behavior Prompting Retrieval

## Summary

This class, part of the "From Zero to AI Agents" curriculum, focuses on understanding the behavior of Large Language Models (LLMs), exploring prompting techniques, and introducing Retrieval Augmented Generation (RAG). Students learn about how LLMs predict tokens probabilistically, the impact of context windows, and strategies for steering the model's output. The class culminates in building a personal wiki using local Gemma and RAG, enabling offline question answering from user-defined data.

## Key Concepts

*   **LLM Token Prediction:** LLMs operate by predicting the next token in a sequence, based on probabilistic models.
*   **Prompting:** Techniques for guiding the LLM’s output, including using "thinking mode" and shaping the probability distribution.
*   **Context Windows:** The limitations of LLM context windows and strategies for managing information retrieval.
*   **Fine-tuning and RLHF:** The processes of adapting base LLMs into specialized assistants, including the associated costs.
*   **RAG (Retrieval Augmented Generation):** Combining LLMs with external data sources (like a personal wiki) to improve accuracy and reduce hallucinations.
*   **Local Gemma:** Utilizing a Gemma LLM locally, enabling offline operation and reducing reliance on external services.
*   **Personal Wiki CLI:** Building a command-line interface for the personal wiki, integrating local Gemma and RAG.
