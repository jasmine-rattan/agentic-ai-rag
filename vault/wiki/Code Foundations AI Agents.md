# Code Foundations AI Agents

**Summary:**
This introductory class focuses on the foundational understanding of code and programming, crucial for effectively utilizing and managing AI agents like Claude Code and Codex. It emphasizes that code is the core of AI tools and that understanding it is essential for making informed decisions, debugging issues, and ensuring safe and effective AI deployments. The class aims to equip participants with the basics needed to read, understand, and interact with code generated by AI, rather than requiring them to become professional software developers.

**Key Concepts:**
*   **Code as a Recipe:** Code is presented as a precise set of instructions, analogous to a recipe, that a computer executes.
*   **Binary Fundamentals:**  Understanding that computers operate on binary code (1s and 0s) forms the basis for understanding how software functions.
*   **AI Tool Dependency:** AI tools (Claude Code, Codex, etc.) generate code, and that code is what drives their functionality.
*   **Importance of Understanding Code:**  Regardless of whether you write code directly, the ability to read and interpret code is vital for managing AI systems, evaluating their outputs, and mitigating potential risks.
*   **Key Programming Concepts:** Introduction to fundamental programming elements like variables, conditionals, loops, and functions, illustrated through a browser-based exercise.
